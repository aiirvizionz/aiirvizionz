## Lo que construyo


Me interesa especialmente el punto donde las interfaces limpias, las APIs, los datos y los sistemas inteligentes se encuentran. Mis proyectos y exploraciones públicas abarcan:


- Productos asistidos por IA y aplicaciones orientadas a flujos de trabajo
- Desarrollo web con énfasis en experiencias prácticas para los usuarios
- Python, APIs, bases de datos y prototipos de aprendizaje automático
- Privacidad, seguridad, infraestructura Web3 y colaboración open source
- Herramientas pequeñas que hacen más fáciles de entender las ideas complejas
